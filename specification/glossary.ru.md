# Глоссарий SSAD

[Английская версия](glossary.md)

| Термин | Определение |
|---|---|
| Аналитическая перспектива | Значимое представление системы, отвечающее на определённый класс вопросов об ответственности, поведении, данных или границах |
| Канонический владелец | Основное место, ответственное за определение значимого факта |
| Контекстное использование | Локальное повторение достаточного объёма информации для объяснения использования канонического знания |
| Архитектура знаний | Модель владения системными знаниями и отношений между ними |
| Процесс анализа | Процесс обнаружения и стабилизации знаний, управляемый их зависимостями |
| Модель изменений | Процесс развития знаний при изменении системы |
| Change Surface / область влияния изменения | Набор канонических владельцев, границ, контрактов, данных и инвариантов, затронутых изменением |
| Подтверждение | Источник, поддерживающий утверждение о текущем или целевом поведении |
| Системный синтез | Межкомпонентное знание, собранное на ближайшем общем системном уровне |
| Baseline | Знание, достаточно стабильное для использования как исходная основа более глубокого анализа |
| Stable | Знание, достаточно проверенное для использования как канонический источник до изменения системы или появления новых подтверждений |
| Сопровождающий знания | Роль, поддерживающая документальное представление соответствующего знания |
