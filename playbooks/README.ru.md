# Практические сценарии

Практические сценарии применения SSAD будут добавляться после дополнительной проверки фундамента на examples и реальных applications.

Предполагаемые сценарии:

```text
новая система
существующая система
новая функция
изменение интеграции
архитектурное изменение
миграция устаревшей документации
```

Практические сценарии должны описывать повторяемый рабочий процесс, а не навязывать одну архитектуру системы.
