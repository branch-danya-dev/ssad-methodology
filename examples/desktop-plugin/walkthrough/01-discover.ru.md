# 01 — DISCOVER / собрать подтверждения

[Английская версия](01-discover.md)

## Вопрос

Что нам действительно известно до проектирования структуры документации?

Поскольку пример является синтетическим, следующие утверждения считаются **заданными предпосылками сценария**, а не подтверждениями реальной реализации.

В настоящем реальное применение их роль выполняли бы решения заинтересованных сторон, код, контракты или наблюдаемое поведение.

## Заданные предпосылки

`E-01` — Плагин выполняется внутри настольного приложения-хоста CAD.

`E-02` — Пользователь выбирает один или несколько листов в текущем открытом документе.

`E-03` — Приложение-хост предоставляет плагину возможность экспорта в PDF.

`E-04` — Пользователь выбирает локальную директорию назначения.

`E-05` — Плагин создаёт один PDF для каждого выбранного листа.

`E-06` — Плагин записывает `export-manifest.json` с результатами экспорта.

`E-07` — Ошибка одного листа не удаляет уже успешно сформированные результаты.

`E-08` — Операция экспорта не должна изменять исходный документ CAD.

`E-09` — В исходной версии нет серверной части, удалённого API, облачной БД или модели учётной записи.

## Первоначальные неизвестные

```text
OPEN-01
Что происходит, если файл назначения уже существует?

OPEN-02
Как именно API хоста представляет идентификатор листа?

OPEN-03
Экспорт хоста синхронный или асинхронный?

OPEN-04
Какие поля обязательны в export-manifest.json?
```

Вопросы остаются видимыми, но не все из них блокируют следующий этап.
