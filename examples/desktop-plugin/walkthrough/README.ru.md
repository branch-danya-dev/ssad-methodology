# настольный плагин — разбор процесса анализа

[Английская версия](README.md)

Эта директория представляет **временную последовательность анализа**, а не итоговую структуру документации.

Рекомендуемый порядок:

1. [`01-discover.ru.md`](01-discover.ru.md)
2. [`02-bound.ru.md`](02-bound.ru.md)
3. [`03-own.ru.md`](03-own.ru.md)
4. [`04-model.ru.md`](04-model.ru.md)
5. [`05-connect.ru.md`](05-connect.ru.md)
6. [`06-synthesize.ru.md`](06-synthesize.ru.md)
7. [`07-verify.ru.md`](07-verify.ru.md)
8. [`08-stabilize.ru.md`](08-stabilize.ru.md)

Результатом разбор процесса является стабильная структура знаний в [`../baseline/`](../baseline/).

```text
walkthrough/
→ как мы пришли к знаниям

baseline/
→ где стабильные знания должны находиться
```

Для обучения разбор процесса показан последовательно. В реальной работе анализ может быть итеративным, ветвиться и возвращаться к более ранним этапам.
