# 03 — OWN / определить владельцев

[Английская версия](03-own.md)

## Вопрос

Кто владеет каждым значимым решением и состоянием?

## Таблица владения

| Знание / состояние | Канонический владелец | Потребители |
|---|---|---|
| выбранные листы открытого документа | Приложение-хост | Плагин |
| идентичность исходного документа | Приложение-хост | Плагин, манифест |
| идентификатор и имя листа | Приложение-хост | Плагин, манифест |
| оркестрация экспорта | Плагин | Пользователь |
| статус экспорта отдельного листа | Плагин | Манифест, пользователь |
| физическое сохранение PDF | Файловая система | Пользователь, плагин |
| содержание манифеста | Плагин | Пользователь / будущая автоматизация |
| физическое сохранение манифеста | Файловая система | Пользователь |
| правило неизменности исходного документа | Бизнес-перспектива | Плагин, проверка |
| сквозной инвариант экспорта | Системная перспектива | все перспективы |

## Важные различия

### Состояние хоста не становится состоянием плагина

Плагин может временно сохранить снимок идентификаторов выбранных листов, но это не делает его каноническим владельцем идентичности листа.

### Физическое хранение не владеет смыслом экспорта

Файловая система сохраняет байты, но не решает, считается ли задание экспорта успешным.

### Результат плагина не равен результату хоста

Хост сообщает результат отдельной операции экспорта. Плагин интерпретирует несколько результатов и формирует итоговый пользовательский результат задания.
