# Перспектива файловой системы

[Английская версия](README.md)

## Ответственность

Файловая система владеет физическим сохранением:

```text
сформированных файлов PDF
export-manifest.json
существующих выходных файлов
```

Она не владеет семантическим смыслом результата экспорта.

## Правила сохранения

`FS-01` — Успешно сформированный PDF остаётся доступным, пока более поздняя явно подтверждённая операция не заменит его.

`FS-02` — Ошибка последующего листа не должна удалять успешный PDF другого листа.

`FS-03` — Существующий файл не должен разрушительно перезаписываться без явного согласия.

`FS-04` — Неудачная попытка замены не должна уничтожать ранее корректный файл.

## Стратегия конфликта

Концептуальный базовая версия допускает:

```text
явное согласие на перезапись
```

или:

```text
формирование свободного имени файла
```

Точный пользовательский интерфейс здесь не является каноническим знанием.

## Сохранение манифеста

Плагин владеет содержанием манифеста, а файловая система физически его сохраняет.

Если запись манифеста завершилась ошибкой после создания PDF, система должна сообщить об отказе и не притворяться, что манифест существует.

Сквозная интерпретация принадлежит [`../system/`](../system/).

## Граница

Технологические детали файловой системы намеренно не задаются. Пример моделирует ответственность хранения, а не реализацию операционной системы.
