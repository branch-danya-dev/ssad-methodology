# настольный плагин — стабильный базовая версия

[Английская версия](README.md)

Эта директория является **стабильным результатом разбор процесса, организованным по устройству системы**.

Она намеренно не повторяет этапы рабочего процесса.

```text
baseline/
├── business/
├── plugin/
├── host-application/
├── filesystem/
└── system/
```

Каждая область владеет своим классом канонических знаний.

| Перспектива | Каноническая ответственность |
|---|---|
| [`business/`](business/) | продуктовое поведение, область анализа, бизнес-правила, приёмка |
| [`plugin/`](plugin/) | оркестрация экспорта и смысл результата задания |
| [`host-application/`](host-application/) | авторитетность исходного документа и граница экспорта хоста |
| [`filesystem/`](filesystem/) | физическое хранение и безопасная обработка конфликтов |
| [`system/`](system/) | сквозной сценарий и межперспективные инварианты |

Временный процесс, сформировавший этот базовая версия, описан отдельно в [`../walkthrough/`](../walkthrough/).

> **Разбор процесса объясняет построение. Базовая версия выражает владение.**
