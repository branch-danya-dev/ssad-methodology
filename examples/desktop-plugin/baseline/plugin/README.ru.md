# Перспектива плагина

[Английская версия](README.md)

## Ответственность

Плагин владеет **оркестрацией задания экспорта и интерпретацией результатов**.

Он не владеет каноническим состоянием исходного документа или физическим сохранением файлов.

## Входные данные

От приложения-хоста:

```text
идентичность исходного документа
идентификаторы выбранных листов
имена листов
результат экспорта каждого листа
```

От пользователя:

```text
директория назначения
согласие на перезапись, когда оно требуется
```

## Состояние задания

```text
Idle
  ↓
Preparing
  ↓
Exporting
  ↓
WritingManifest
  ↓
Completed
```

Ошибка отдельного листа фиксируется в задании и не завершает обработку остальных листов автоматически.

## Общий результат

```text
SUCCESS
→ успешны все выбранные листы

PARTIAL_SUCCESS
→ есть хотя бы один успех и хотя бы одна ошибка

FAILED
→ не удалось экспортировать ни одного выбранного листа
```

## Семантическое владение манифестом

Плагин владеет смыслом и содержанием:

```text
sourceDocumentId
exportedAt
outputDirectory
items[]
  sheetId
  sheetName
  fileName
  status
  errorCode?
```

Файловая система только физически сохраняет сформированные данные.

## Граница

Плагин использует возможности хоста, описанные в [`../host-application/`](../host-application/), и правила хранения из [`../filesystem/`](../filesystem/).

Межкомпонентное поведение принадлежит [`../system/`](../system/).
