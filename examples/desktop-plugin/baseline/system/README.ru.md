# Системный синтез

[Английская версия](README.md)

## Назначение

Эта перспектива владеет знаниями, которые одновременно затрагивают бизнес-поведение, оркестрацию плагина, авторитетность хоста и физическое хранение.

## Контекст системы

```text
          Пользователь
              │
              ▼
     [ Sheet Export Plugin ]
         │             │
         │             ▼
         │      Локальная файловая система
         │
         ▼
приложение-хост CAD
```

## Сквозной сценарий

```text
Выбор пользователя
→ подготовка плагина
→ экспорт каждого листа через хост
→ физическое сохранение
→ агрегация результата плагином
→ сохранение манифеста
→ итог для пользователя
```

## Системные инварианты

`SI-01` — Содержимое исходного документа не изменяется заданием экспорта.

`SI-02` — При успешном создании манифеста каждый выбранный лист имеет в нём ровно одну запись.

`SI-03` — Успешный PDF не удаляется из-за последующей ошибки другого листа.

`SI-04` — `SUCCESS` требует успеха всех выбранных листов.

`SI-05` — `FAILED` означает, что ни один выбранный лист не был успешно экспортирован.

`SI-06` — Ошибка экспорта не должна уменьшать множество корректных ранее существовавших выходных файлов.

## Карта авторитетности

```text
Состояние исходного документа
→ Приложение-хост

Интерпретация задания экспорта
→ Плагин

Физическое сохранение результатов
→ Файловая система

Требуемое наблюдаемое поведение
→ Бизнес-правила

Межперспективные инварианты
→ Системный синтез
```

## Граница базовая версия

Сетевой интеграции или внешней системы управления документами пока нет.

Если последующее изменение их добавляет, необходимо пересмотреть модель границ, а не просто дописать вызов HTTP в документацию плагина.

См. [`../../changes/dms-upload/`](../../changes/dms-upload/).
