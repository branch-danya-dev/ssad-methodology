# Бизнес-перспектива

[Английская версия](README.md)

## Назначение

Позволить пользователю настольного приложения CAD экспортировать выбранные листы чертежа в локальные файлы PDF без изменения исходного документа.

## В области анализа

- экспорт выбранных листов;
- локальная директория назначения;
- отдельный результат для каждого выбранного листа;
- итоговый результат задания;
- манифест экспорта;
- безопасное поведение при существующих выходных файлах.

## Вне области анализа

- редактирование документа CAD;
- облачное хранение;
- учётные записи;
- удалённая совместная работа;
- интеграция с системой управления документами;
- сетевой транспорт.

## Бизнес-правила

`BR-01` — Экспорт не должен изменять исходный документ.

`BR-02` — Каждый выбранный лист обрабатывается независимо.

`BR-03` — Ошибка одного листа не должна удалять уже успешно сформированные результаты других листов.

`BR-04` — После обработки всех выбранных листов пользователь получает итоговый результат.

`BR-05` — Существующие выходные файлы не должны разрушительно перезаписываться без явного согласия пользователя.

## Приёмка

Исходная версия считается приемлемой, если:

- для каждого выбранного листа существует записанный результат;
- успешные PDF сохраняются после ошибки другого листа;
- исходный документ остаётся неизменным;
- существующие файлы защищены согласно `BR-05`;
- итог различает полный успех, частичный успех и полный отказ.
