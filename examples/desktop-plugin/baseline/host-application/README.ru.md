# Перспектива приложения-хоста

[Английская версия](README.md)

## Ответственность

приложение-хост CAD является авторитетным источником для:

```text
открытого исходного документа
идентичности документа
идентичности листа
имени листа
текущего выбора листов
возможности экспорта в PDF
```

Плагин может использовать или временно копировать эти значения, но не становится их каноническим владельцем.

## Концептуальный контракт

Плагину необходимы возможности, эквивалентные:

```text
getDocumentIdentity()
getSelectedSheets()
exportSheetToPdf(sheetId, targetPath)
```

Точные имена API, сигнатуры, синхронность и объекты конкретного производителя намеренно находятся за пределами синтетического пример.

## Граница изменения документа

Сценарий экспорта не должен требовать изменения исходного документа.

Это поддерживает [`BR-01`](../business/).

## Поведение при отказе

Хост может сообщить об ошибке экспорта отдельного листа.

Хост не определяет итог всего задания из нескольких листов. Эта интерпретация принадлежит плагину.

## Открытые вопросы реализации

```text
OPEN-02
Точное представление идентичности листа.

OPEN-03
Точное синхронное или асинхронное поведение экспорта.
```

Эти вопросы не нарушают стабильность концептуального базовая версия.
