# Example — событийная платформа

[Английская версия](README.md)

> **Статус:** синтетический пример  
> **Назначение:** показать распределённое владение, асинхронные контракты и отдельную эксплуатационную перспективу.

## Сценарий

Вымышленная платформа обработки заказов принимает заказ, резервирует товар, инициирует оплату и публикует события для исполнения заказа.

Допущения:

```text
сервис заказов
сервис остатков
платёжный сервис
брокер сообщений
отдельные базы сервисов
внешний платёжный провайдер
контейнерная платформа
система наблюдаемости
```

## Возможные перспективы SSAD

```text
business/
services/
messaging/
data/
integrations/
operations/
system/
```

Структура снова следует реальным зонам ответственности, а не шаблону мобильного или веб-продукта.

## Пример владения

```text
жизненный цикл заказа
→ сервис заказов

доступность товара
→ сервис остатков

внутреннее состояние попытки оплаты
→ платёжный сервис

внешнее состояние транзакции
→ платёжный провайдер

инфраструктура доставки сообщений
→ messaging

развёртывание / наблюдаемость / восстановление
→ operations
```

## Пример асинхронного контракта

Событие:

```text
InventoryReserved
```

Смысл события не принадлежит Kafka как технологии.

Семантический контракт принадлежит системной ответственности, публикующей этот факт, а документация сообщений владеет транспортным поведением и инфраструктурными ограничениями.

То есть разделяются:

```text
смысл бизнес- или системного события
≠
технология передачи сообщений
```

## Пример области влияния изменения

Запрос:

> Разрешить повторять оплату в течение 24 часов, не освобождая резерв товара.

Вероятное влияние:

```text
Бизнес-правила        ДА
Сервис заказов        ДА
Сервис остатков       ДА
Платёжный сервис      ДА
Сообщения             ДА
Жизненный цикл данных ДА
Внешняя интеграция    ДА
Отказы / восстановление ДА
Эксплуатация          ВОЗМОЖНО
Системные инварианты  ДА
```

## Намеренные упрощения

Пример не утверждает существование реальных топиков Kafka, кода сервисов, схем, SLA, манифестов развёртывания или контрактов провайдера.
