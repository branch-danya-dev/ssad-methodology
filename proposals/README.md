# Methodology Proposals

Material methodology changes should enter through explicit proposals when they are not ready to become accepted decisions.

```text
Observed problem
→ synthetic example exploration and/or real-world application evidence
→ Proposal
→ Validation
→ Accept / Reject / Revise
→ Specification update
```

Examples may explore consequences. Applications provide real-world evidence.

Suggested format: `RFC-001-title.md`.
