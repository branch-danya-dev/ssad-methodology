# Предложения по развитию методологии

Значимые изменения SSAD следует сначала оформлять как явные предложения, если они ещё не готовы стать принятыми решениями.

```text
обнаруженная проблема
→ исследование на синтетическом example и/или подтверждение через реальное application
→ предложение
→ проверка
→ принять / отклонить / доработать
→ обновить спецификацию
```

Examples позволяют исследовать последствия. Applications дают подтверждение реальной практикой.

Предлагаемый формат: `RFC-001-title.md`.
