# 03 · Analysis

[Русская версия](README.ru.md)

This section contains the **analytical toolkit of SSAD**.

If workflow answers “what should I do at work?”, analysis answers:

> **How do I decompose a system and reason about it?**

```text
BOUNDARIES
RESPONSIBILITIES
OWNERSHIP
BEHAVIOR
STATES
DATA
INTERFACES
INTEGRATIONS
FLOWS
TRUST
FAILURES
SYNTHESIS
```

These are not mandatory folders. They are analytical questions that should have explicit answers when relevant.

Each topic follows a practical learning pattern: problem → idea → questions → method → result → example → diagram → mistakes → verification.
