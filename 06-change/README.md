> What will the change actually affect, and which knowledge must be reopened?

```text
CHANGE REQUEST
→ INITIAL SCOPE
→ AFFECTED RESPONSIBILITIES
→ AFFECTED OWNERS
```

Topics include impact analysis, Change Surface, compatibility, reopening stable knowledge and stabilization after implementation.
