This section shows **what SSAD looks like in practice**.

Examples are not a separate showcase. They support and validate the theory in the previous sections.

```text
Synthetic
→ inexpensive exploration of a focused idea

Real-world
→ validation against an actual system and real constraints
```

## Primary real-world example

**Aveli**

https://github.com/branch-danya-dev/aveli-system-analysis

Aveli demonstrates the core SSAD idea: system knowledge is organized around actual system responsibilities instead of a universal catalog of analytical artifact types.

Small learning slices from Aveli will be used here for boundaries, ownership, repository structure, access flows, integrations and changes.
