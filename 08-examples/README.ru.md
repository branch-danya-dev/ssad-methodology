# 08 · Examples

Этот раздел показывает, **как SSAD выглядит на практике**.

Примеры нужны не как отдельная витрина, а как подтверждение теории из предыдущих разделов.

## Типы примеров

```text
Synthetic
→ дешёвое исследование отдельной идеи

Real-world
→ проверка подхода на реальной системе и реальных ограничениях
```

## Основной реальный пример

### Aveli

Полный репозиторий системного анализа:

https://github.com/branch-danya-dev/aveli-system-analysis

Aveli показывает ключевую идею SSAD: база системного знания построена вокруг реальных областей системы, а не вокруг универсального набора типов аналитических документов.

```text
business/
database/
backend/
frontend/
integrations/
system/
```

В этом разделе будут собраны небольшие учебные срезы Aveli:

- определение границ;
- ownership;
- структура репозитория;
- серверный access flow;
- взаимодействие frontend ↔ backend ↔ RevenueCat;
- изменение существующего решения.

Каждый срез будет ссылаться на полное каноническое описание в репозитории Aveli.

## Принцип примеров

> **Теория должна показывать не только правильное утверждение, но и то, как оно выглядит в реальной системе.**
