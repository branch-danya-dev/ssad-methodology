# 07 · Practice

[Русская версия](README.ru.md)

This section turns SSAD into a **day-to-day working reference for system analysts**.

It does not repeat the theory from Workflow, Analysis, Knowledge Structure, Collaboration and Change. Its purpose is to provide a short path into that theory from a concrete work situation.

## How to use it

Start from the problem you have at work, not from SSAD terminology.

```text
Work situation
      ↓
short checklist
      ↓
minimum useful output
      ↓
links to deeper theory
```

## What Practice is not

These checklists are not mandatory forms to complete in full. They are navigation and reasoning aids.

Use only the questions relevant to the task. When the problem is complex, follow the links into the deeper methodology chapters.

> **Practice starts from a real work situation and leads to the required analysis depth instead of forcing the reader to remember the methodology structure.**
