# Review & Grooming checklist

[Русская версия](README.ru.md)

Use this when validating a solution with the team and preparing it for implementation.

Review asks whether the solution is correct across business, architecture, development, QA, integration, security and operations perspectives.

Grooming asks whether the team shares the same implementation understanding: scope, dependencies, contracts, acceptance criteria and remaining open questions.

Ready check:

```text
Purpose understood        ✓
Scope defined             ✓
Affected components known ✓
Ownership defined         ✓
Contracts described       ✓
States / edge cases known ✓
Open questions resolved   ✓
Acceptance criteria clear ✓
Dependencies known        ✓
```

When review exposes a new fact, update the canonical knowledge owner rather than patching only the local task text.
