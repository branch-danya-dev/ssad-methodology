# 07 · Practice

Этот раздел превращает методологию в **ежедневный рабочий инструмент системного аналитика**.

## Главный вопрос

> Что открыть и чем воспользоваться, когда у меня уже есть конкретная рабочая задача?

## Здесь будут собраны

- вопросы для предварительного анализа;
- вопросы для сбора требований;
- вопросы по интеграциям;
- вопросы по данным и ownership;
- вопросы по API и контрактам;
- review-checklists;
- grooming-checklists;
- change-impact checklists;
- типичные ошибки;
- короткие сценарии применения.

## Пример использования

```text
Мне нужно проанализировать новую интеграцию
        ↓
practice / integration questions
        ↓
analysis / boundaries + ownership + interfaces
        ↓
workflow / review
```

Practice не заменяет теорию из других разделов. Он даёт короткий маршрут к ней из реальной рабочей ситуации.

Следующий раздел: [`08-examples/`](../08-examples/).
