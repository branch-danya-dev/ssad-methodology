# Pre-analysis checklist

[Русская версия](README.ru.md)

Use this when a new task arrives and you need to understand what is actually being requested before deep analysis.

Check:
- problem and expected outcome;
- requester and affected users;
- need versus suggested implementation;
- initial system boundaries;
- known constraints;
- relevant participants;
- known facts, assumptions and open questions.

Minimum output:

```text
Problem / goal
Initial scope
Known constraints
Affected actors/systems
Known facts
Assumptions
Open questions
Next participants
```
