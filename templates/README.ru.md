# Шаблоны

Повторно используемые шаблоны намеренно отложены до дополнительной проверки фундамента на синтетических examples и новых реальных applications.

Предполагаемые шаблоны:

```text
компонент
технология
интеграция
область влияния изменения
владение данными
системный синтез
проверка качества
```

Шаблоны должны стандартизировать полезные формы документов, но не превращать структуры examples в обязательные деревья директорий.
