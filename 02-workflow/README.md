# 02 · Workflow

[Русская версия](README.ru.md)

This section answers the practical question:

> **I received a task. What do I do as a system analyst?**

```text
PRE-ANALYSIS
→ REQUIREMENTS
→ ANALYSIS & DESIGN
→ SPECIFICATION
→ REVIEW
→ GROOMING
→ DELIVERY SUPPORT
→ VERIFICATION
→ KNOWLEDGE UPDATE
```

SSAD does not replace the delivery process with an artificial lifecycle. It explains what the analyst needs to obtain, do, discuss and verify at each stage.

The process is iterative: new evidence found during review, implementation or QA can reopen earlier analysis.
