В этой директории фиксируются **принятые решения, существенно влияющие на саму SSAD**.

## Принятые решения

|---|---|---|---|
| [ADR-001](ADR-001-perspectives-over-folder-templates.ru.md) | Аналитические перспективы вместо шаблона директорий | Принято | Реальное применение — Aveli |

## Жизненный цикл решения

```text
обнаруженная проблема
→ исследование на example и/или подтверждение через application
→ предложение или кандидат на прямое решение
→ проверка
→ принятое решение
→ обновление спецификации
```

Синтетические examples позволяют недорого исследовать решение.

Реальные applications дают более сильное подтверждение, потому что методология сталкивается с настоящими ограничениями проекта.

Для ещё не принятых идей используется `proposals/`.

Решение методологии обычно должно содержать:

```text
контекст
решение
последствия
подтверждение
статус
```

Редакционные изменения, не меняющие поведение методологии, не требуют отдельного ADR.
