# 04 · Knowledge Structure

[Русская версия](README.ru.md)

This section explains how analysis results become a **readable, precise and navigable system knowledge base**.

> Documentation should reflect the real system and its responsibility areas.

There is no mandatory SSAD folder tree. The structure should make it easy to answer where knowledge belongs, why it belongs there, who owns it, what it connects to, and how deeply a reader needs to continue.

Topics include decomposition, document responsibility, canonical knowledge, contextual links, navigation, depth and the difference between useful system-shaped structure and blindly copying a source tree.
