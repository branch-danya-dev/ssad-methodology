# Реальные применения

[Английская версия](README.md)

В этой директории перечислены **реальные проекты, которые действительно документируются по SSAD**.

Applications отличаются от синтетических examples:

```text
example
→ иллюстративный
→ может быть полностью вымышленным
→ оптимизирован для объяснения принципа

application
→ реальный проект
→ реальные ограничения
→ реальная документация
→ практическое подтверждение методологии
```

Реальное применение может обнаружить проблему, которая приведёт к новому предложению, ADR, изменению рабочего процесса или спецификации.

## Текущие применения

| Применение | Тип системы | Репозиторий | Влияние на методологию |
|---|---|---|---|
| [Aveli](aveli/) | локальное мобильное приложение | [aveli-system-analysis](https://github.com/branch-danya-dev/aveli-system-analysis) | привела к появлению нескольких базовых правил и явного рабочего процесса SSAD |

## Как добавить применение

Проект относится сюда, когда:

- проект является реальным;
- SSAD действительно используется для организации или сопровождения системно-аналитических знаний;
- связанный репозиторий или документация могут служить подтверждением применения;
- полученные выводы можно связать с развитием методологии.

Вымышленные учебные сценарии сюда не добавляются. Для них используется [`../examples/`](../examples/).
