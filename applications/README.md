# Real-World Applications

[Русская версия](README.ru.md)

This directory lists **real projects that are actually documented using SSAD**.

Applications are different from synthetic examples:

```text
example
→ illustrative
→ may be fictional
→ optimized to explain a principle

application
→ real project
→ real constraints
→ real documentation
→ practical evidence for the methodology
```

A real-world application may expose problems that lead to a proposal, ADR, workflow change, or specification change.

## Current Applications

| Application | System type | Repository | Methodology impact |
|---|---|---|---|
| [Aveli](aveli/) | local-first mobile application | [aveli-system-analysis](https://github.com/branch-danya-dev/aveli-system-analysis) | produced several foundation rules and the explicit SSAD workflow |

## Adding an Application

A project belongs here when:

- the project is real;
- SSAD is actually used to structure or maintain its analysis knowledge;
- the linked repository or documentation can serve as evidence of application;
- lessons learned can be traced back to the methodology.

Do not place fictional teaching scenarios here. Use [`../examples/`](../examples/) for those.
