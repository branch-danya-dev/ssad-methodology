# Рабочий процесс SSAD

[Английская версия](README.md)

Рабочий процесс SSAD не является жизненным циклом разработки и не задаёт обязательную последовательность совещаний. Он описывает **зависимости знаний**.

## Построение модели системы

```text
DISCOVER → BOUND → OWN → MODEL → CONNECT → SYNTHESIZE → VERIFY → STABILIZE
```

См. [`construction.ru.md`](construction.ru.md).

## Анализ изменений

```text
Запрос на изменение → область влияния → анализ последствий → обновление знаний → проверка → Stable
```

См. [`change-analysis.ru.md`](change-analysis.ru.md).

## Непрерывное сопровождение

```text
Изменилась реализация или решение
→ найден канонический владелец
→ обновлено знание
→ проверены ссылки
→ проверена трассируемость
→ проверены противоречия
```

См. [`maintenance.ru.md`](maintenance.ru.md).

## Основное правило

> **Строй и изменяй знания в порядке их зависимостей. Не путай зависимость с бюрократией.**
