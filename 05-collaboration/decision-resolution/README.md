# Decision Resolution

Real teams often provide incompatible answers. This is not necessarily bad communication; it is often a real conflict between requirements, constraints and evidence.

Classify the conflict first:

- fact conflict;
- requirement conflict;
- constraint conflict;
- ownership conflict.

Do not resolve conflicts by voting. Determine authority, mandatory constraints, available evidence, feasible alternatives and the consequences of each option.

A practical sequence is:

```text
conflicting claims
→ source / evidence / authority
→ mandatory constraints
→ alternatives
→ consequences and risks
→ decision owner
→ decision
→ canonical knowledge update
```

A decision record explains rationale and alternatives. It does **not** replace the canonical model of current system behavior.

> Disagreement becomes useful when it is converted into an explicit decision and improves the system model.
