# Визуальные материалы

[Английская версия](README.md)

В этой директории находятся визуальные материалы для представления методологии.

## Текущие схемы

| Материал | Назначение |
|---|---|
| [`ssad-model.ru.svg`](ssad-model.ru.svg) | Обзор трёх моделей SSAD |
| [`analysis-workflow.ru.svg`](analysis-workflow.ru.svg) | Процесс построения знаний по зависимостям |

Английские версии:

```text
ssad-model.svg
analysis-workflow.svg
```

Машиночитаемые исходники хранятся рядом с отрисованными материалами:

```text
ssad-model.puml
ssad-model.ru.puml
analysis-workflow.puml
analysis-workflow.ru.puml
```

Визуальные материалы служат для представления. Нормативный смысл остаётся в `specification/` и `workflow/`.
