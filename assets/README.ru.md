# Визуальные материалы

[English version](README.md)

`assets/` содержит вспомогательные визуальные материалы и их исходники.

Они нужны для презентации и развития методологии, но **не являются самостоятельным каноническим слоем знания**.

## Где находится актуальный смысл

Канонические определения находятся в reader-first разделах:

```text
01-foundation/
02-workflow/
03-analysis/
04-knowledge-structure/
05-collaboration/
06-change/
07-practice/
08-examples/
```

Если визуальная схема расходится с текстом соответствующей главы, канонической считается глава.

## Форматы

```text
*.puml
→ редактируемые PlantUML-исходники

*.svg
→ подготовленные presentation renders
```

Главный `README.ru.md` использует Mermaid для основных публичных схем, чтобы они всегда находились рядом с актуальным объяснением методологии.

> **Визуализация помогает понять знание. Владельцем знания остаётся соответствующая глава SSAD.**
